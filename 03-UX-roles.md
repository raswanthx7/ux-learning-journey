#  Core UX Knowledge & Roles 

##  Introduction

User Experience (UX) is not a single role — it is a **collaborative field made up of multiple specialized roles** working together to build a product that is useful, usable, and enjoyable.

In real-world companies (especially MNCs), UX work is **divided into focused roles**, each responsible for a specific part of the product experience.

---

##  Key Understanding

* UX is a **team effort**, not an individual task
* Each role contributes to a **different layer of the product**
* Strong products come from **clear role separation + collaboration**

---

##  Core UX Roles

---

###  Interaction Designer

**Focus:** Product behavior and user flow

**Responsibilities:**

* Defines how users move from one screen to another
* Designs interaction logic (e.g., button → next action)
* Creates wireframes and user flows

**Example:**

* Clicking “Add to Cart” → What happens next?

---

###  Visual Designer (UI Designer)

**Focus:** Product appearance

**Responsibilities:**

* Colors, typography, layout
* Visual hierarchy and branding
* Making interfaces aesthetically appealing

**Example:**

* Button color, font style, spacing

---

###  Motion Designer

**Focus:** Animation and transitions

**Responsibilities:**

* Page transitions
* Micro-interactions (button animations, loading effects)
* Enhancing user experience through motion

**Example:**

* Smooth screen transition when opening an app

---

###  UX Researcher

**Focus:** User understanding

**Responsibilities:**

* Conducts user interviews (qualitative)
* Runs surveys/data analysis (quantitative)
* Identifies user pain points

**Example Questions:**

* What problems do users face?
* Is the product easy to use?

---

###  UX Writer

**Focus:** Product language

**Responsibilities:**

* Button labels (e.g., “Search”, “Buy Now”)
* Error messages
* Microcopy and tone of voice

**Goal:**
Make the product **clear and understandable**

---

###  UX Engineer

**Focus:** Bridge between design and development

**Responsibilities:**

* Converts design into working product
* Ensures feasibility of design
* Works with both designers and developers

---

###  Conversation Designer

**Focus:** Voice and chat interactions

**Responsibilities:**

* Chatbot flows
* Voice assistant interactions
* Natural conversation experience

---

##  Management Roles in UX/Product

---

###  Product Manager (PM)

**Focus:** Product vision and strategy

**Responsibilities:**

* Defines **what to build and why**
* Aligns business goals with user needs
* Prioritizes features
* Works with stakeholders, engineers, and UX team

**Key Thinking:**

* Why are we building this?
* Is this valuable for users and business?

---

###  UX Program Manager

**Focus:** Execution and coordination

**Responsibilities:**

* Manages timelines
* Ensures smooth collaboration within UX and teams
* Organizes workflow and processes

**Key Thinking:**

* Are we on track?
* Is the team working efficiently?

---

##  Difference: Product Manager vs UX Program Manager

| Aspect         | Product Manager | UX Program Manager    |
| -------------- | --------------- | --------------------- |
| Focus          | Strategy        | Execution             |
| Responsibility | Product vision  | Team coordination     |
| Key Question   | What & Why?     | How & When?           |
| Scope          | Entire product  | UX process & delivery |

---

##  How These Roles Work Together

* **UX Researcher** → Finds user problems
* **Product Manager** → Defines solution direction
* **Interaction Designer** → Designs flow
* **Visual Designer** → Designs UI
* **Motion Designer** → Adds interaction feel
* **UX Writer** → Adds clarity through text
* **UX Engineer** → Builds the experience
* **UX Program Manager** → Keeps everything on track

---

##  Final Understanding

* UX is **not just design**, it is a system
* Each role solves a **specific layer of the experience**
* Collaboration is the **core of product success**

---

##  Conclusion

To grow in UX:

* Understand **all roles**
* Master **one core area first (UX Design)**
* Learn how to **collaborate across teams**
