#  UX Learning Journey — Usable, Useful, Equitable

##  Introduction

When designing a product (like a mobile app or website), it's not enough for it to *just exist* — it must solve real problems and be easy for people to use.

A good user experience (UX) ensures that:
- Users can **achieve their goals easily**
- The product **actually solves their needs**
- Everyone can **access and use it fairly**

This is where three key concepts come in:
> **Usable, Useful, and Equitable**

---

##  1. Usable

### 🔹 Definition
A product is **usable** if users can **easily interact with it without confusion**.

### 🔹 Key Questions
- Can users understand what to do?
- Is it easy to navigate?
- Can users complete tasks without errors?

### 🔹 Examples
- Search bar → **Usable**
- Add to cart button → **Usable**
- Checkout button → **Usable**
- Profile icon → **Usable**
- Back to browse → **Usable**

 These are actions. If they are easy to use, they are usable.

---

##  2. Useful

### 🔹 Definition
A product is **useful** if it **solves a real problem or fulfills a user’s need**.

### 🔹 Key Questions
- Does this feature help the user achieve their goal?
- Is this feature necessary?

### 🔹 Examples
- Filter options (finding specific food) → **Useful**
- Choosing pizza size (small/medium/large) → **Useful**
- Selecting quantity → **Useful**
- Viewing product details → **Useful**
- Seeing price → **Useful**
- Customizing pizza toppings → **Useful**

 These features give **value**, not just function.

---

##  3. Equitable

### 🔹 Definition
A product is **equitable** if it is **accessible and usable by all types of users**, regardless of ability or situation.

### 🔹 Key Questions
- Can people with disabilities use it?
- Does it support different languages or needs?
- Is it inclusive?

### 🔹 Examples
- Language translation (Tamil ↔ English, Hindi ↔ English) → **Equitable**
- Voice support for visually impaired users → **Equitable**
- Adjustable font size or contrast → **Equitable**

 This is about **inclusivity**.

---

##  4. Enjoyable 

### 🔹 Definition
A product is **enjoyable** if it creates a **pleasant and satisfying experience**.

### 🔹 Examples
- Attractive food images → **Enjoyable**
- Smooth UI animations → **Enjoyable**
- Clean design → **Enjoyable**

---

##  Quick Comparison

| Concept     | Focus                          | Example                  |
|------------|-------------------------------|--------------------------|
| Usable     | Easy to use                    | Add to cart button       |
| Useful     | Solves a problem               | Filter food items        |
| Equitable  | Accessible to everyone         | Voice + translation      |
| Enjoyable  | Feels good to use              | Food images UI           |

---

##  Real Insight

A great product should be:
-  Usable (easy)
-  Useful (valuable)
-  Equitable (inclusive)
-  Enjoyable (delightful)

If even one is missing, the experience becomes weak.

---

##  Final Thought

> A product that is only usable but not useful is **pointless**.  
> A product that is useful but not usable is **frustrating**.  
> A product that is not equitable is **exclusive**.  

The goal of UX design is to balance all of them.
