## 1. What Is an Empathy Map?

An empathy map is a chart that helps UX designers organize what they learn about a particular type of user.

It breaks down interview information into four areas:

- Says
- Thinks
- Does
- Feels

The purpose is to make interview information easier to understand and analyze.

---

## 2. Why Do We Use an Empathy Map?

A user interview can contain a lot of information.

An empathy map helps organize that information so the UX designer can better understand:

- The user's perspective
- The user's needs
- The user's pain points
- The user's behavior
- The user's emotions
- The user's thoughts and concerns

The basic process is:

Interview
-> Raw information
-> Empathy Map
-> Understand the user
-> Identify needs and pain points
-> Make better design decisions

The empathy map is not the final UX solution. It is a tool for organizing and analyzing research.

---

## 3. What Do I Learn by Doing an Empathy Map?

By creating an empathy map, I learn how to analyze user interviews instead of simply reading them.

I learn to separate:

- What the user actually says
- What the user thinks or needs
- What the user actually does
- What the user feels

I also learn to distinguish evidence from my own assumptions.

Most importantly, I learn to look for patterns in user research that can help me understand the real problem before designing a solution.

---

## 4. What Happens If I Don't Do an Empathy Map?

Empathy maps are not required for every UX project. They are one of many UX research tools.

However, if I skip the underlying skill of analyzing interviews, I may:

- Design based on my own assumptions
- Miss the user's actual pain points
- Confuse what users say with what they actually do
- Treat my interpretation as a fact
- Miss patterns across different users
- Build features that users may not actually need

For example:

A user says:

> "I apply to lots of jobs, but I forget which ones I've applied to. I use LinkedIn and write some things in Notes. When I have multiple interviews, I get stressed."

Without properly analyzing the interview, I might think:

> "The user needs more job listings."

But the interview may actually indicate a problem with:

> Managing and tracking job applications.

The important lesson is:

> Empathy mapping is not about drawing four boxes. It is about learning how to analyze user research correctly.

# 5. Says

## Meaning

"Says" contains the user's exact words from the interview.

The course describes these as verbatim quotes.

## What Does Verbatim Mean?

Verbatim means:

> Word-for-word or exactly as the user said it.

Example:

User says:

> "I really wish I had one place to keep track of all my applications."

Says:

> "I really wish I had one place to keep track of all my applications."

Do not change the wording when recording a verbatim quote.

### Incorrect for Says

> User wants one place to track applications.

This is a summary, not a verbatim quote.

### Important Point

If a user says what they want, it can still go under Says because the user literally said it.

Example:

> "I want an app that reminds me when I have an interview."

If those are the user's exact words, this belongs in Says.

---

# 6. Thinks

## Meaning

"Thinks" represents thoughts, needs, wants, or concerns expressed by the user and carefully summarized by the UX designer.

It does not have to be written as an exact quote.

Example:

User says:

> "I really wish I had one place to keep track of all my applications."

Thinks:

> Wants one place to keep track of applications.

The wording is different, but the meaning is grounded in what the user said.

## Important Rule

Thinks does not mean that I can randomly guess what the user is thinking.

I need evidence from the interview.

### Reasonable inference

User talks about the difficulty of finding an experienced dog walker.

Possible inference:

> Wants a dog walker with experience with animals.

### Unsupported assumption

> Definitely wants an adult dog walker with a driver's license.

This would be an assumption unless the interview provides evidence for it.

---

# 7. Does

## Meaning

"Does" contains the user's actual actions or behaviors.

Ask:

> What does the user actually do?

Example:

User says:

> "I usually scroll LinkedIn at night to look for new job posts."

Does:

> Scrolls LinkedIn at night to look for new job posts.

Other examples:

- Checks email for interview details.
- Writes important interview dates in the phone's Notes app.
- Walks the dogs in the morning and evening.
- Pays a neighbor to walk the dogs.

## Important Rule

Does is about actual behavior, not what the user wants to do.

### Not Does

> Wants a way to track applications.

This is a thought or need.

### Does

> Writes application details in Notes.

This is actual behavior.

---

# 8. Feels

## Meaning

"Feels" contains the emotions the user expresses or that can be carefully identified from the interview.

Example:

User says:

> "It gets stressful when I have several interviews in the same week, because I'm afraid I might miss one."

Feels:

> Stressed and afraid of missing an interview.

Other possible feelings include:

- Frustration
- Worry
- Sadness
- Guilt
- Excitement

If the user does not clearly express an emotion, the UX researcher can ask:

> "How does this make you feel?"

---

# 9. The Difference Between the Four

| Section | Main Question | Example |
|---|---|---|
| Says | What did the user literally say? | "I forget which jobs I've already applied to." |
| Thinks | What thought, need, or concern can I summarize from their words? | Wants an easier way to track applications. |
| Does | What does the user actually do? | Scrolls LinkedIn at night. |
| Feels | What emotion is the user experiencing? | Feels stressed about missing interviews. |

---

# 10. Verbatim vs Emotion

Verbatim and emotion are different concepts.

Verbatim describes how information is recorded.

Emotion describes what the user feels.

Example:

> "I keep forgetting which jobs I applied for."

If this is exactly what the user said:

- It is a verbatim quote.
- It belongs in Says.

It may suggest frustration, but I should not automatically label the user as frustrated unless the interview provides evidence for that emotion.

### Explicit emotion

> "It's really frustrating because I keep forgetting which jobs I applied for."

Now frustration is directly expressed and can be included in Feels.

---

# 11. How to Analyze an Interview

When reading an interview, ask four questions:

### Says

> What exact words did the user say?

Use quotation marks when appropriate.

### Thinks

> What thoughts, needs, wants, or concerns can I carefully summarize from the user's statements?

### Does

> What actions or behaviors does the user actually perform?

### Feels

> What emotions does the user express or clearly demonstrate?

---

# 12. Practice Example

Interview:

> "I usually scroll LinkedIn at night to look for new job posts, but I forget which ones I've already applied to. I really wish I had one place to keep track of all my applications. Before an interview I normally check my email again to find the details. It gets stressful when I have several interviews in the same week, because I'm afraid I might miss one. I also write important interview dates in my phone's Notes app."

### Says

> "I forget which ones I've already applied to."

> "I really wish I had one place to keep track of all my applications."

> "Before an interview I normally check my email again to find the details."

### Does

- Scrolls LinkedIn at night to look for new job posts.
- Checks email for interview details.
- Writes important interview dates in the phone's Notes app.

### Feels

- Stressed when there are several interviews in the same week.
- Afraid of missing an interview.

### Thinks

- Wants one place to keep track of applications.
- Wants an easier way to manage interview information.
- Wants to quickly access interview dates and details.

---

# 13. One-User Empathy Map

A one-user empathy map is created from the interview of a single user.

It includes that person's:

- Says
- Thinks
- Does
- Feels

This makes one user's interview easier to analyze.

---

# 14. Aggregated Empathy Map

An aggregated empathy map represents a group of users who share similar thoughts, opinions, or qualities.

The process is:

1. Create individual empathy maps.
2. Compare the maps.
3. Combine similar information.
4. Identify common patterns and themes.
5. Use those themes to better understand user groups.

---

# 15. Main Takeaways

1. Empathy maps organize user interview information.
2. Says uses the user's exact words.
3. Verbatim means word-for-word.
4. Thinks summarizes thoughts, needs, wants, and concerns based on evidence.
5. Does records actual user behavior.
6. Feels records emotions expressed or carefully identified from research.
7. A user saying what they want can still belong in Says if those are their exact words.
8. Thinks is not limited to what the user literally says; it can be a careful summary of their thoughts, needs, or concerns.
9. Do not turn assumptions into facts.
10. Empathy maps can help identify common themes across multiple users.
11. An empathy map is a research-organizing tool, not the final UX solution.
12. The bigger skill is learning how to analyze user research and understand the user's real problem before designing.
