## Goal Quality Check

Before finalizing a goal, ask:

- [ ] Is it focused on the user?
- [ ] Is it about something we need to learn?
- [ ] Is it connected to the problem?
- [ ] Is it specific enough to research?
- [ ] Is it NOT already assuming a solution?
